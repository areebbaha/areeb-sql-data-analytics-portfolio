## Featured Project

### Hospital Patient Care Operations Analytics

**MySQL Business Analytics Project**

A practical SQL analytics project designed to understand hospital patient care operations using relational data.

The project analyzes five interconnected tables:

- Patients
- Appointments
- Treatments
- Doctors
- Rooms

### Dataset

| Table | Records |
|---|---:|
| Patients | 400 |
| Appointments | 3,000 |
| Treatments | 3,500 |
| Doctors | 80 |
| Rooms | 50 |

### Business Questions

The project investigates questions related to:

- Patient and appointment demand
- Appointment behaviour
- Treatment performance
- Doctor workload
- Room utilization
- Waiting time
- Cancellations
- No-shows
- Rescheduled appointments
- Repeated treatment attempts
- Operational problem areas

### SQL Techniques Used

The project applies:

- Filtering
- Aggregation
- GROUP BY
- HAVING
- CASE
- JOINs
- Subqueries
- CTEs
- Window Functions
- Ranking
- Date-based analysis
- Business-oriented SQL analysis

### Key Project Findings

Some of the major findings from the hospital analysis include:

- Appointment demand differs across cities and booking channels.
- The App is a major source of appointment demand.
- General patients contribute the largest estimated appointment value.
- Completed treatments are the dominant treatment outcome.
- Doctor workload and room utilization are uneven.
- Some rooms have both high workload and above-average waiting time.
- Problem rates vary across cities.
